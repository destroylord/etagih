**eTagih** adalah aplikasi invoice open source untuk freelancer dan agensi kecil di Indonesia:
klien & proyek, time tracking, pembayaran QRIS, pengingat WhatsApp & email, dan PDF invoice profesional —
dijalankan di server kamu sendiri.

:::tip{title="Mau langsung mencoba?"}

Ikuti [Instalasi dengan Docker](/memulai/instalasi-docker) untuk server produksi (VPS 1 GB sudah cukup),
atau [Instalasi manual](/memulai/instalasi-manual) untuk mencoba di laptop.

:::

## Fitur utama

| Fitur | Ringkasan |
|---|---|
| **Invoice** | Harga tetap atau per jam, bayar penuh atau cicilan 2–24 kali, diskon, PPN, invoice berulang, duplikat, pembatalan. |
| **Klien → Proyek → Sub-proyek** | Misalnya *PT Maju Jaya → Toko Online → Aplikasi Mobile, Dashboard Admin*. Invoice, item, dan jam kerja dikelompokkan per proyek. |
| **Pembayaran QRIS** | QRIS dinamis lewat QRISLY, verifikasi status ke gateway, pencatatan transfer manual, alokasi cicilan otomatis. |
| **Kode QR bergaya** | Warna, bentuk titik & sudut, bingkai berjudul, dan logo di tengah. |
| **Notifikasi** | WhatsApp (Fonnte) dan email dengan PDF terlampir, plus pengingat sebelum & sesudah jatuh tempo. |
| **PDF profesional** | Kop, watermark, terbilang, QR pembayaran, syarat & ketentuan, tanda tangan. |
| **Time Tracker** | Stopwatch per klien/proyek dengan jeda, pembulatan, dan antrean offline. |
| **Task & tim** | Task per proyek dengan board, checklist, komentar, dan pengingat tenggat. Undang tim lewat email; staf hanya melihat proyek yang diikuti. Task selesai langsung ditagih ke invoice. |
| **Di HP** | Tampilan mobile dengan navigasi bawah, bisa dipasang sebagai aplikasi (PWA). |
| **Laporan** | Pendapatan bulanan, umur piutang, klien teratas, per proyek, export Excel. |
| **Portal klien** | Klien melihat dan membayar semua invoicenya dengan kunci akses. |
